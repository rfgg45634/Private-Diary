# Private Diary · 私人日记

一个简洁、温暖、本地存储的 Android 日记与知识卡片 App。
Kotlin + Room + ViewBinding，无网络权限，所有数据只存在本机。

## 功能

### 日记
- 按日期记录每一天，自动生成标题与时间标签
- 每张卡片左侧根据"每月几号"显示一张专属水彩小画（1~31 号）
- 日间 / 夜间模式自动记忆，夜间为暖灰底柔字，不刺眼
- 连续记录天数 + 累计记录天数常驻头部
- 全文搜索（标题 + 正文）
- 回收站：删除的记录保留 7 天后自动清除

### 知识卡片
- 只记标题的极简卡片，书签式居中排版
- 长按拖拽排序
- 与日记模块共用日间 / 夜间主题

## 构建

- Android Studio Hedgehog 以上 / JDK 22
- `./gradlew assembleDebug`
- Release 请使用你自己的 keystore 签名，仓库内不包含任何密钥

## 说明

- 包名 `com.example.mydiary`，可自由二次开发
- 数据全部存在本机 Room 数据库，不上传任何服务器
