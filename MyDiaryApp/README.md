# 我的日记 App - 说明文档

## "更新"
包名（applicationId）没有变，数据库结构也在用规范的迁移方式处理，直接覆盖安装到手机上
就是正常的版本更新，现有的日记/知识数据会完整保留，不会清空。

---

## 功能总览（当前完整版本）

### 知识模块
- 卡片仅显示标题（不显示正文预览，保护隐私）
- 长按卡片右上角的拖拽手柄可以自由排序，排序立即保存
- 支持**左滑卡片**直接移入回收站（会弹出"撤销"提示，误删可以立刻恢复）
- 支持**按标题搜索**，点头部搜索图标展开搜索框，实时过滤

### 日记模块
- 卡片显示标题 + 创建时间小标签
- 默认按创建时间降序排列，头部有排序按钮可以切换成升序（最早在前）
- 底部翻页栏，每页固定条数
- 同样支持**左滑删除**和**按标题搜索**（搜索时会临时隐藏翻页栏，显示全部匹配结果）
- 连续记录满2天以上，头部会显示"🔥 已连续记录 X 天"

### 编辑页（两个模块共用）
- 标题留空时自动用创建时间作为默认标题，顶部导航栏会实时同步显示当前标题+模块图标
- 支持把光标所在的段落**居中**，可以当作正文里的小标题使用；网上滑动时，标题区域会自动切换成
  显示"当前所属的小标题"，标题输入框本身隐藏，滑回顶部才会切回来
- 正文下方有**正文内搜索**功能（顶部菜单的搜索图标），支持高亮所有匹配项、跳转上一个/下一个
- 右下角悬浮显示实时字数统计
- 输入后自动保存（防抖），标题正文都留空直接退出的话，这条记录会被丢弃，不会留下空文件
- 删除会先移入回收站，7天内可恢复

### 回收站
- 显示所有已删除内容，标注还剩几天会被永久清除
- 可以单条恢复或彻底删除，也可以一键清空

### 其他
- 完全离线运行，没有任何网络权限
- 支持日夜模式（跟随系统 + 手动切换按钮），配色分别调过，不是简单的黑白反转
- 左右滑动即可在知识/日记模块之间切换，跟点底部导航栏效果一致
